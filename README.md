🍳 Gerenciador de Receitas
────୨ৎ────────୨ৎ────────୨ৎ────

Este projeto é um mini sistema desenvolvido para facilitar o cadastro e o gerenciamento de receitas. Nele, é possível adicionar novas receitas com informações como nome, ingredientes e tempo de preparo.

Funcionalidades

O sistema possui algumas funções para facilitar a organização das receitas:

Cadastrar receitas: permite adicionar uma nova receita informando seu nome, ingredientes e tempo de preparo.
Visualizar receitas: mostra a lista de receitas que já foram cadastradas.
Atualizar receitas: permite editar as informações de uma receita já existente.
Excluir receitas: permite remover uma receita do sistema.
Cadastro e login: possui opções para criar uma conta, entrar no sistema e sair.

Sobre o sistema

Na página inicial, o usuário encontra um menu com as principais opções do Gerenciador de Receitas. A partir dele, é possível acessar o cadastro, consultar as receitas e realizar alterações quando necessário.

O sistema foi criado com o objetivo de praticar a criação de um sistema completo, trabalhando com cadastro, consulta, atualização e exclusão de informações.

Objetivo

O objetivo do projeto foi desenvolver um sistema simples e organizado para guardar receitas e facilitar o acesso às informações dos pratos, além de colocar em prática os conhecimentos aprendidos durante as aulas.
